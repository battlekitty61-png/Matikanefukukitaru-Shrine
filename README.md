# Matikanefukukitaru Shrine

A fan-made Matikanefukukitaru shrine website with fortunes, daily luck, achievements, Shiraoki-sama summoning, hidden events, and an AI chatbot powered by OpenRouter.

## AI setup

Set the Vercel Production environment variable `Fuku_Key` to your OpenRouter API key. Optionally set `OPENROUTER_MODEL`; the default is `openrouter/free`.

Never commit an API key to this repository.
